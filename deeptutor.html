How does the Multi-Head Self-Attention mechanism compute queries, keys, and values?

Multi-Agent Reasoning Chain 3 Citations Grounded
  • 1. [RAG Engine] Retrieved "Attention Is All You Need" (Vaswani et al.) Section 3.2.
  • 2. [Cognitive Model] Learner understands basic matrix multiplication; needs visual breakdown of scaled dot-product.
  • 3. [Socratic Goal] Explain linear projections first, formulate question on why dimension d_k scaling prevents vanishing gradients.

In Self-Attention, an input sequence is projected into three distinct representations through learned weight matrices:

Q = X · W_Q  |  K = X · W_K  |  V = X · W_V

We then compute the scaled dot-product attention formula:

Attention(Q, K, V) = softmax((Q · Kᵀ) / √d_k) · V

Socratic Question for You: Why do we divide by √d_k inside the softmax rather than directly passing Q · Kᵀ? What happens to the gradients when d_k grows very large?

The 8 Learning Surfaces

Unlike single-window chatbots, DeepTutor integrates eight synchronized modalities designed for deep conceptual retention.

1. Chat Workspace

Multi-agent conversation with real-time citations, LaTeX equations, and dynamic code execution environments.

2. Persistent Partner

An evolving AI companion that remembers past roadblocks, preferred learning pace, and conceptual blindspots.

3. Co-Writing Canvas

Interactive markdown and LaTeX canvas for collaborative thesis drafting, problem proofs, and technical essays.

4. Books & RAG Hub

Ingest PDFs, textbooks, lecture recordings, and research papers with zero hallucination and verifiable page citations.

5. Mind Map Synthesis

Automated visual knowledge graphs revealing prerequisite pathways and cross-disciplinary connections.

6. Adaptive Quizzes

Dynamically calibrated testing tailored to challenge misconceptions with diagnostic feedback.

7. Spaced Flashcards

Leitner retention scheduling backed by neuro-cognitive algorithms to ensure zero knowledge decay over months.

8. Mastery Analytics

Granular skill breakdown with competence maps, velocity stats, and recommended review dates.

Three-Layer Persistent Memory

Standard LLM chats lose context as soon as a window closes. DeepTutor's three-tier memory architecture stores interactions at distinct temporal resolutions, ensuring your learning journey compounds forever.

Tier 1: Ephemeral Working Buffer

Maintains immediate conversation turn history, active scratchpad derivations, and tool outputs.

Tier 2: Mid-Term Topic Knowledge

Tracks active course modules, solved problem sets, and diagnostic misconception markers.

Tier 3: Lifelong Cognitive Profile

Stores deep cognitive strengths, learning preferences, and lifelong milestone achievements.
